\begin{abstract}
We evaluate seventy-two priority queue and routing algorithm combinations on a scale-free graph of the Moscow road network containing 1.2 million nodes. 
Our study reveals microarchitectural isomorphism, where priority queue memory layout scales step execution latency but leaves macro-topological search space complexity exponents unchanged. 
We construct a three-step filtering pipeline to identify optimal routing configurations based on complexity exponents, node re-opening metrics, and hardware jitter stability. 
Our benchmarks demonstrate that SimdRadixHeap is the optimal priority queue backend for monotone ALT queries, delivering 3147 QPS for localized queries and 631 QPS for megalopolis journeys. 
For non-monotone queries, we recommend our vectorized cache-conscious Simd8AryHeap.
\end{abstract}
