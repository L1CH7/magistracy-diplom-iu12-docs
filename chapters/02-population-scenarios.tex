\section{Архитектура подсистемы управления популяциями IPopulationManager}
\label{sec:population_arch}

Для обеспечения непрерывности и физической достоверности жизненного цикла агентов разработан интерфейс \texttt{IPopulationManager}. В отличие от систем с независимым спавном отдельных поездок, модуль сохраняет идентичность агента между поездками, реализуя цепочки перемещений (\emph{trip chaining}): «Дом $\rightarrow$ Работа $\rightarrow$ Коммерция $\rightarrow$ Дом».

Архитектура модуля включает:
\begin{itemize}
    \item Менеджер генерации локаций спавна на базе узлов графа в жилых и производственных зонах;
    \item Очередь активных агентов с динамическим распределением статусов;
    \item Контроллер профилей активного объема, регулирующий количество автомобилей на дорогах в каждый момент симуляции.
\end{itemize}

\section{Моделирование суточных циклов активности}
\label{sec:diurnal_cycles}

Интенсивность появления агентов на дорожной сети определяется суточным профилем объемной активности (\emph{diurnal active volume curve}). Коэффициент активной популяции $R(t) \in [0.125, 1.0]$ изменяется по часам суток согласно дискретному профилю с непрерывной $SmoothStep$-интерполяцией.

Для популяции в $N_{\text{max}} = 70\,000$ агентов число автомобилей, находящихся в движении в момент времени $t$, вычисляется по формуле:
\begin{equation}
N_{\text{active}}(t) = N_{\text{max}} \cdot R(t).
\label{eq:active_agents}
\end{equation}

\section{Пространственное распределение и маятниковая миграция}
\label{sec:pendulum_migration}

Структура транспортного потока разделена на четыре категории агентов:
\begin{enumerate}
    \item \textbf{Маятниковый трафик (\emph{Commuters}, 65\%)}: Поездки между жилыми массивами и центральным деловым районом.
    \item \textbf{Коммерческий трафик (\emph{Commercial}, 20\%)}: Непрерывные циклические поездки грузового и таксомоторного транспорта.
    \item \textbf{Случайный фоновый трафик (\emph{Random}, 10\%)}: Корреспонденции между произвольными узлами сети.
    \item \textbf{Общественный транспорт (\emph{Public Transport}, 5\%)}: Движение по фиксированным кольцевым маршрутам.
\end{enumerate}
