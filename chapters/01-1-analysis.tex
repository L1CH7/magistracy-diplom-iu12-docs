\section{Сравнительный обзор подходов к агент-ориентированному моделированию и навигации}

При проектировании навигационных комплексов для современных мегаполисов одной из наиболее острых проблем является выбор правильной архитектурной парадигмы управления транспортными потоками. Дорожная сеть большой размерности (например, Московская агломерация содержит порядка 600 тысяч сегментов дорог и 1,5 миллиона возможных маневров) ставит перед исследователями серьезные вычислительные вызовы. В рамках данной научно-исследовательской работы был проведен сравнительный анализ применимости современных математических и алгоритмических подходов к решению задачи агент-ориентированной навигации и планирования транспортных систем \cite{yakimov2013planning, yakimov2022planning_visum}.

Большинство передовых парадигм (2022–2026 гг.) математически состоятельны, однако их практическая реализация в условиях жестких ограничений по времени отклика (латентности) и объему оперативной памяти затруднена. Результаты отсева представлены в таблице \ref{tab:paradigms_comparison}.

Анализ, представленный в таблице \ref{tab:paradigms_comparison}, показывает, что применение чистых концептуальных парадигм в исходном виде невозможно из-за вычислительных ограничений. По этой причине архитектура разработанного комплекса строится на базе гибридного подхода, объединяющего элементы низкоуровневой оптимизации памяти и модифицированный алгоритм поиска пути:

1. Представление графа сети в памяти (на основе идей GraphBLAS):
Вместо объектно-ориентированного представления графа используется формат сжатого хранения строк (CSR) \cite{drepper2007memory, buluc2017design}. Данные ребер и вершин размещаются в плоских непрерывных массивах. Это исключает разыменование указателей и активирует аппаратный механизм предвыборки процессора. Вычислительно затратные матричные операции GraphBLAS при этом исключены.

2. Кэш-локализация (на основе идей пространственного хеширования):
Пространственное индексирование на базе кодов Мортона (Z-кривой) \cite{morton1966computer} перенесено на этап предобработки. Координаты узлов отображаются в одномерный индекс для физической сортировки структуры CSR в памяти. Это гарантирует размещение топологически близких участков дорог в смежных кэш-линиях процессора, снижая частоту промахов кэша L3 и предотвращая ложное разделение данных между ядрами \cite{butorin2026thread}. Поиск путей по ячейкам координатной сетки не используется из-за несовместимости с правилами маневрирования.

3. Учет динамической загруженности (на основе концепции стигмергии):
Динамические изменения плотности потока фиксируются через механизм временных интервалов резервирования емкости ребер. Запись проезда агента увеличивает плотность потока в соответствующем интервале резервирования. Этот подход является детерминированной реализацией цифровых феромонов роевого интеллекта. Время проезда ребра вычисляется за $O(1)$ без перестройки топологии графа. Вероятностный характер исходной парадигмы роевого поиска заменен строгим детерминированным расчетом.

4. Базовый алгоритм поиска пути (ALT-маршрутизация):
Для ускорения поиска путей применен алгоритм ALT \cite{goldberg2004alt}. Использование нижних граней расстояний до маяков по неравенству треугольника заменяет евклидову эвристику классического $A^*$. Это сохраняет корректность оценок на направленных графах с учетом задержек на маневры. Данные расстояний упакованы в структуру массивов (SoA), что позволяет рассчитывать потенциалы вершин параллельно с помощью инструкций AVX2 \cite{butorin2026thread}. При этом двунаправленный поиск исключен из-за отсутствия временного детерминизма при пошаговом бронировании ребер.


На основе проведенного анализа был сделан вывод о высокой вычислительной сложности классического автономного агентного подхода для поставленной задачи. Попытка индивидуального моделирования поведения каждого агента ведет к значительному снижению производительности.

В связи с этим в разработанной системе обоснован и применен гибридный подход, основанный на декомпозиции вычислительных слоев \cite{butorin2026thread}:
\begin{itemize}
    \item Делегирование функций принятия решений на макроуровень. Агент представляет собой компактную (порядка 100 байт), пассивную структуру данных без индивидуального контура управления, которая следует по заданному пути в соответствии с законами одномерной кинематики.
    \item Вычислительное ядро маршрутизации. Модуль работает без сохранения состояния, выполняя расчет кратчайших путей по зависимым от времени весам ребер графа.
    \item Макроскопический модуль принятия решений. Логика диспетчеризации вынесена на макроуровень, где осуществляется глобальный мониторинг состояния сети и инициируется перерасчет маршрутов при снижении средней скорости движения на сегментах.
\end{itemize}

Такая декомпозиция (пассивный агент~-- бесконтекстный роутер~-- интеллектуальный диспетчер) решает проблему вычислительной сложности и позволяет реализовать алгоритмы диспетчеризации (регулирование пропускной способности, оптимизацию макропараметров) без необходимости автономного обучения каждого агента.
