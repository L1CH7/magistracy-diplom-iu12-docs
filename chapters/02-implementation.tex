\section{Выводы по второй главе}
В главе описана программная реализация ядра маршрутизации. Разработанная архитектура изолирует вычислительные слои на основе паттернов инверсии управления и эффективного размещения данных в памяти. 

Разработанный конвейер предварительной обработки сжимает реляционные картографические данные в плоские бинарные массивы компактного формата, применяя алгоритмы пространственного упорядочивания на основе Z-кривой Мортона для минимизации промахов кэша процессора. Использование векторных SIMD-инструкций для работы с 8-арной кучей и пространственными сетками кратно ускоряет критические участки кода, а механизм отображения файлов в виртуальную память исключает задержки при старте системы. Передача телеметрии через безблокировочную очередь в выделенный фоновый поток изолирует сетевые задержки от вычислительного ядра, гарантируя работу ядра в режиме реального времени.
