\section{Выводы по второй главе}
В главе описана программная реализация ядра маршрутизации. Разработанная архитектура изолирует вычислительные слои на основе паттернов инверсии управления и эффективного размещения данных в памяти. 

Разработанный конвейер предварительной обработки сжимает реляционные картографические данные в плоские бинарные массивы компактного формата, применяя алгоритмы топологической пересортировки для минимизации промахов кэша процессора. Использование векторных SIMD-инструкций для работы с многоарными кучами и пространственными сетками кратно ускоряет критические участки кода, а механизм отображения файлов в виртуальную память исключает задержки при старте системы. Внедренная шина событийного обмена сообщениями отделяет передачу телеметрии от вычислительного потока, гарантируя работу ядра в режиме реального времени.
